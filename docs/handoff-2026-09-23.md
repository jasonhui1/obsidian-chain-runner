# Handoff: UI review, 2026-09-23

A review of the plugin's UI from the user's side, which became a redesign of how
a hold is answered on the drawing. Jason works mainly on the Excalidraw drawing,
with the directing panel in the sidebar.

## Settled

**ADR-0016, "A hold on the drawing is a fork point"** (accepted, on main). A
waiting hold is drawn as a column of candidates, stacked, each showing its whole
text. Each answered candidate grows a row of output cards to its right; a later
pick forks into a row of its own. Output cards are small previews, read whole in
the directing panel. No run ids are shown to the reader. `CONTEXT.md` gained
**Hold column** and **Pick row**.

Jason's preferences, stated this session:
- Candidates stacked in a column because a list is easier to read, not to save
  height. Height is not a constraint.
- He dislikes text that is collapsed and has to be clicked open.
- Run ids mean nothing to a reader; name runs by what makes them different.
- Price is noise while exploring. Don't show costs.
- Keep the directing panel's tabs.

## Next session: the chat UI

Jason wants to redesign chat. He wasn't sure it exists. It does, in three
places:
- the directing panel's proposal tab, "Chat with <name>", with a box and
  "Use this reply as the revision & rerun" (`src/ui/directingBoard.ts`, `chat()`);
- "Ask the room" on the panel's Run tab (`room()`);
- the hold note's `## Conversation`, as typed trigger lines (`@name message`,
  `ask the room: …`, `side quest: @name chain`), and the palette commands
  (`src/ui/holdCommands.ts`, ADR-0014).

Chat should absorb three ideas he preferred to button versions of:
- asking about a candidate before picking it (the engine can chat with the
  decider that wrote the candidates);
- steering new candidates ("more like this") — the reply becomes a reroll's
  feedback;
- combining two candidates — the reply becomes the reader's own candidate
  (`custom`).

It should reach the candidates on a hold column (ADR-0016). Start by asking what
he dislikes about the current chat before designing.
